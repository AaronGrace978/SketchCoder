# Linux / Steam Deck

SketchCoder is an Electron desktop app.

## AppImage (easiest)

1. Download `SketchCoder-Linux-x64.AppImage`
2. `chmod +x SketchCoder-Linux-x64.AppImage`
3. Run it

## tar.gz

1. Extract `SketchCoder-Linux-*.tar.gz`
2. Run the `SketchCoder` binary inside

## Steam Deck as non-Steam game

1. Install / place the AppImage somewhere stable (e.g. `~/Applications`)
2. Steam → Add a Game → Add a Non-Steam Game
3. Browse to the AppImage
4. Optional: set the hero art from `steam-hero.png` if you keep it next to the build
